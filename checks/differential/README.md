# differential: does Lean's model agree with the real implementation?

The Lean proofs reason about Lean's own definitions of how Graphix builds patterns. These tests run those
definitions (through the `mbqc_counts` executable, `lean/Main.lean`) and Graphix itself on the same inputs and
require identical results. `lean_counts` compares N, E and M; `lean_gate_streams` compares the J/CZ stream token
for token, gate kind by gate kind. Two independent implementations agreeing is strong evidence that the Lean
definitions mean what we intend.

Shared code: `_streams.py` (Graphix streams as text for Lean).
