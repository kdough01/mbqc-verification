# translation: does the compiled pattern implement its circuit?

Instead of proving a compiler correct in general, translation validation checks each output. The tests simulate
the compiled pattern or graph state and the circuit on many inputs and require them to agree. A pass is
**bounded**: it is a check of those instances only, up to floating point. Large patterns cannot be simulated, so
the instances are small ones.

`graphix_pattern` runs Graphix here. `recorded_compiler` reads the runs `experiments/compilers/run.py`
recorded for a compiler in its own environment (Cabaliser).
