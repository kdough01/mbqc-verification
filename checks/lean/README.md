# lean: is the statement proved in Lean?

The node's `lean_decl` names a Lean theorem. These tests build the Lean project once per run and read
`#print axioms`. Standard axioms (propext, Quot.sound, Classical.choice) are fine. Axioms under
`MBQC.Assumptions.*` are fine when an assumption node declares them: the proof then holds **modulo** those
assumptions, and they become the node's frontier. Anything else (sorry, an undeclared axiom) and the proof does
not count.

A passing proof also says which other nodes' declarations it reaches. dagtool uses that to check the DAG's
declared edges against the proof (`edge_mismatch`, `edge_unused`).

`proof` proves the claim; `disproof` proves its negation and so refutes the claim ("Disproved in Lean").
